# 🚗 Al Suwaidi Auto Repair Website

A modern, responsive, and SEO-optimized auto repair website built for **Al Suwaidi International Garage LLC, Dubai**.

This project showcases a professional business website built using **Next.js 14, React, TypeScript, and Tailwind CSS**, focusing on performance, user experience, and search engine optimization.

---

## 🌐 Live Website

🔗 https://alsuwaidiautorepair.com/

---

## 📸 Project Overview

The goal of this project was to create a modern online presence for an automotive repair business, allowing customers to:

- Learn about services
- Explore repair solutions
- Contact the garage
- Request bookings
- Find business information easily

The website was designed with a focus on **SEO, mobile responsiveness, and fast performance**.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Rafisayed13/autorepair.git
```

Navigate into the project:

```bash
cd autorepair
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
